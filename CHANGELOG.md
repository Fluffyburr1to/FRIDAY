## How this file will be maintained

From the first release, entries are generated by **Changesets** and assembled during the release
process ([Chapter 27](docs/01-bible/27-cicd-pipeline.md)). Changesets is not installed yet — it is
release machinery, and there is nothing to version until Milestone 4 produces something installable.
Adding it now would mean maintaining a release configuration for three milestones before it does
anything.

Two rules for entries, whenever they start:

1. **Written for the owner, not for a programmer.** "Gmail now waits longer before retrying, because
   it was giving up too early on large attachments" — not "refactored the connector retry layer."
2. **Changes FRIDAY proposed herself are marked as such.** Provenance stays visible permanently, the
   same way the `ai-authored` label does on pull requests.
