# Diagrams

**Mermaid source, in text.** Never binary images, never external diagramming tools.

## Why text

- **Diagrams appear in diffs.** A change to the architecture shows as a change to the diagram.
- **AI assistants can read them.** A rendered PNG is invisible to two of this project's three
  audiences.
- **They render everywhere** — GitHub, editors, and the terminal.

ASCII diagrams are used freely where they are clearer than Mermaid. Several appear directly in Bible
chapters for exactly that reason.

## Rules

1. **A diagram must be comprehensible without the prose around it** — label everything.
2. **Diagrams live with the chapter they illustrate** where possible. This folder is for diagrams
   referenced from several places.
3. **A diagram that contradicts the code is a defect**, filed as one.
4. **Keep them small.** A diagram showing everything shows nothing. Prefer several focused ones.
