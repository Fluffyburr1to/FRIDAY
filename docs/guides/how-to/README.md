# How-To Guides

**Reader:** working, has a goal, already competent. Answers "how do I accomplish X?"

How-tos assume you know what you are doing and need the steps. They do not explain *why* — that is
the [Project Bible](../../01-bible/) and the [ADRs](../../adr/) — and they do not teach from
scratch, which is what tutorials are for.
