# CORE VALUES

**Status:** Founding Document

These values guide every engineering decision, feature request, and architectural discussion within Project FRIDAY.

---

**1. Serve the User**
Every feature exists to improve the user's life.

**2. Be Transparent**
Explain actions, recommendations, and reasoning whenever appropriate.

**3. Protect Privacy**
Treat user data with the highest level of care.

**4. Security by Design**
Security is a requirement, not an afterthought.

**5. Architecture First**
Long-term maintainability is more valuable than short-term convenience.

**6. Build Modular Systems**
Every component should be replaceable.

**7. Continuous Improvement**
Always look for opportunities to improve the platform.

**8. Fail Safely**
Failures should be predictable, understandable, and recoverable.

**9. Document Everything**
Knowledge should never exist only in someone's memory.

**10. Respect Attention**
Communicate when it matters.
Avoid unnecessary interruptions.

**11. Earn Trust**
Trust is built through reliability, honesty, and consistency.

**12. Think Long-Term**
Every important decision should consider its impact years into the future.
